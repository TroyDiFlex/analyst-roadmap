# Analyst Roadmap

Личный трекер системного обучения для первого трудоустройства на позиции, где анализируют табличные бизнес-данные: junior data analyst, BI/reporting analyst, marketing analyst и commercial analyst.

**Сайт:** [troydiflex.github.io/analyst-roadmap](https://troydiflex.github.io/analyst-roadmap/)

Это не roadmap под одну отрасль. Avito и e-commerce используются только в нескольких необязательных домашних заданиях на знакомом материале.

## Что внутри

- 6 последовательных этапов: SQL → таблицы → анализ и статистический минимум → Power BI → Python/pandas → проект и трудоустройство;
- 41 тема в общей программе; все 12 тем SQL оформлены как последовательные уроки, остальные явно помечены «В разработке»;
- в готовых уроках есть объяснения с нуля, единая учебная таблица, примеры SQL, самостоятельная практика и ответы;
- учебные задания, самопроверки и несколько необязательных задач на знакомых данных;
- заметки, чек-листы, история выполнения и календарь активности;
- локальное резервное сохранение, синхронизация прогресса и экспорт в JSON;
- Obsidian-style dark theme с акцентом `#FB7185`.

Первый цикл откликов начинается после этапа 4. Python и проект продолжаются параллельно с поиском работы.

## Текущая готовность

Готовы 12 уроков SQL для абсолютного новичка: устройство таблицы; SELECT; WHERE; сортировка и DISTINCT; агрегаты; CASE и доли; даты и текст; ключи и связи; JOIN; CTE и подзапросы; оконные функции; проверка результата. В каждом уроке есть объяснения, практика и скрытые ответы. Собственный датасет и предварительное знание SQL не нужны.

Все запросы рассчитаны на SQLite. Дни 1–7 используют таблицу `orders` из дня 2; в день 8 добавляются `customers`, `order_customers` и `payments`. Сохраняются исходные 8 заказов: сумма заказов 19 400, оплаченная сумма 13 700. На отдельных примерах разобраны пустые выборки, кириллица в LOWER, покупатель без заказов, равные ранги и завышение суммы после JOIN. Длинные уроки можно разделить на несколько занятий.

Большие контрольные задания SQL, остальные этапы и итоговые проекты пока в разработке: их галочки отключены, а прогресс по ним не учитывается. Поэтому этап SQL отмечен как частично готовый, хотя все его учебные темы доступны.

## Граница программы

Трек покрывает общее ядро аналитики данных. Он не готовит с нуля к системному/процессному business analysis, data science, data engineering или узкому финансовому анализу: этим профессиям нужны отдельные программы.

Обоснование состава и ограничения исследования описаны в [docs/roadmap-methodology.md](docs/roadmap-methodology.md).

Проверка порядка уроков и исправленные зависимости от будущих тем — в [docs/course-audit.md](docs/course-audit.md). Для SQL не требуются Python, Excel или Power BI. Остальные этапы пока проверены только на уровне планов.

## Запуск

Проект написан на vanilla HTML, CSS и JavaScript. Открой `index.html` через локальный статический сервер, например:

```bash
npm start
```

Проверка: `npm test` (Node.js с модулем `node:sqlite`). Тесты выполняют учебные SQL-примеры и решения, сравнивают ответы и проверяют пограничные случаи. Проверка интерфейса браузером в эту команду не входит.

## Прогресс

Для синхронизации используется тот же секретный ключ, что в исходном трекере. Данные нового roadmap записываются в отдельную ветку объекта и отдельный ключ `localStorage`, поэтому не должны перезаписывать прогресс старого трекера.
